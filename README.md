# 📱 iPhone 15 Pro — Apple-Inspired Website

A modern, responsive iPhone 15 Pro landing page inspired by Apple's product website.  
Built with React and Tailwind CSS, with reusable components and interactive sections to recreate a premium product presentation experience.

## 🚀 Live Demo

🔗 **[View Live Website](https://iphone-website-by-jamolkhon.netlify.app/)**

---

## ✨ Features

- 📱 iPhone 15 Pro product showcase
- 🎨 Apple-inspired minimalist UI
- 📐 Fully responsive design
- ⚡ Component-based React architecture
- 🎬 Interactive video carousel
- 🧊 iPhone model presentation
- 💡 Dynamic lighting section
- ⭐ Product highlights section
- 🧩 Reusable UI components
- 🎯 Modern animations and transitions
- 📱 Mobile-friendly navigation
- 🚀 Production deployment with Netlify

---

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| **React** | UI development and component architecture |
| **Vite** | Development server and build tool |
| **Tailwind CSS** | Styling and responsive design |
| **JavaScript (ES6+)** | Application logic |
| **HTML5** | Page structure |
| **CSS3** | Custom styling and animations |
| **Netlify** | Deployment |
